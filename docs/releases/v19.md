# v19（2026-10-29）

## 新功能
- 新增“补全 QQ 历史记录”：通过可选 NapCat 本机接口，按群聊 / 私聊和秒级时间范围读取历史，合并到现有聊天。
- 支持每页保存断点、暂停后继续、重新检查范围，以及查看最近补全任务。窗口可隐藏至底部，继续显示实际进度与用时。
- 附件独立处理：已有文件引用原路径；可选择下载图片、视频、语音和文件，并单独重试待补齐附件。
- 新增转发聊天记录查看窗口：显示内部发送者的昵称与 QQ 号，支持复制号码、查看本地资料、筛选消息及展开嵌套转发。
- 支持打开 OneBot / NapCat 转发正文 JSON，并在本机保存解析来源，之后可离线查看。
- 支持通过可选的 NapCat 本机 HTTP 接口读取转发正文，读取前核对登录账号，访问令牌仅在当前窗口内使用。
- 旧版仅保存摘要的记录，可从原始数据库只读补取对应卡片标识，无需复制整库或重新导入全部消息。

## 修复
- 区分 QQ 原始序号与接口临时消息标识，避免以错误标识合并历史；同序号下不同时间或发送者的记录保留。
- 历史接口空页、重复页、账号变化和异常响应不再作为完整历史处理；明确显示未验证状态。
- 导入时保留可识别的转发卡片资源标识，避免只剩摘要而无法继续读取正文。
- 缺失发送者号码或时间时显示未知，不使用转发者身份和当前时间代替。
