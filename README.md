# QQ聊天记录管理器

一个在本机运行的 Windows 桌面程序，用来长期保存和管理自己的 QQ 聊天记录。它以只读方式读取电脑 QQ（NT 架构）的加密消息库，导入到本地归档库，并提供浏览、搜索、导出和附件管理。

下载：见 [Releases](../../releases)，提供安装包和便携版。更新内容见 [CHANGELOG.md](CHANGELOG.md)。

## 主要功能

- **导入**：自动发现电脑 QQ 的消息库；可从正在运行的、已登录的电脑 QQ 中只读获取数据库密钥，并用数据库页面认证校验，也可手动填写；支持按会话和时间范围导入。
- **归档**：多账号分类保存；同一消息从不同来源导入时合并去重，内容冲突的版本会保留并标记；导入整批提交，取消或失败会整批撤销。
- **浏览**：仿 QQ 的聊天界面，支持会话分组、置顶、独立聊天窗口，以及按时间定位。
- **搜索**：关键词、多条件组合、时间范围和发送人筛选；可以直接输入 QQ 号查看此人在全部聊天中的发言。
- **导出**：HTML、TXT、CSV、JSON，以及可再次导入的归档包。
- **附件**：关联电脑 QQ 的图片、视频、语音和文件；可通过 USB（ADB）以只读方式从手机外部存储拉取 QQ 附件，支持断点续传和校验。
- **迁移监测**：使用 QQ 自带的“迁移聊天记录到电脑”时，显示迁移连接、写入速率和数据库变化。

## 已知限制

- QQ 官方备份文件目前不能导入，程序会显示“暂不支持导入”和原因。可以改用 QQ 自带的“迁移聊天记录到电脑”，然后导入电脑 QQ 的消息库。
- 未 Root 的手机无法读取 QQ 私有消息数据库；手机端只能拉取外部存储里的附件文件。
- 自动获取密钥与 QQ 版本有关，失败时会给出原因，并可改用手动填写。
- 程序暂不能识别的消息类型会保留并标记，不能据此认定历史记录完整。
- 1–2 个字的关键词需要逐条检查，在大型归档里会比较慢。

## 数据与隐私

- 对 QQ 数据库、备份和手机始终只读，不修改原文件。
- 密钥默认只在本次运行中有效；勾选后才会以 Windows 账户加密（DPAPI）保存在本机。
- 程序不联网上传任何数据。

## 从源码运行

需要 Windows 10/11 x64 和 Python 3.12。

```bash
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe main.py
```

运行测试还需要 `pytest` 和 `sqlcipher3-wheels`（后者只用于生成测试用的加密数据库，不随程序分发）：

```bash
.venv\Scripts\python.exe -m pip install pytest sqlcipher3-wheels
.venv\Scripts\python.exe -m pytest -q
```

构建安装包需要 PyInstaller 和 Inno Setup 6，说明见 [docs/开发说明.md](docs/开发说明.md)。
